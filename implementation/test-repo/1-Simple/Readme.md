# 1. Simple example

Very simple example using a boolean and real stream to get familiar with the language.

It defines a stream `a` which results from adding 5 to the values of input stream `x`.
Then, if input stream `y` is currently true it is checked if `a` is greater than 10, otherwise if `a` is greater than 5.

The output is the same for the symbolic and the ranges approach, and in both cases the best possible.
